## Customer Order Count

### Project Objective
Count unique orders per customer and identify frequent buyers using the Sample Superstore dataset.

### Tools Used
- Microsoft Excel / WPS Office
- Sample Superstore Dataset

### Work Completed

- Created unique Customer ID–Order ID combinations.
- Removed duplicate Customer–Order combinations.
- Created a Customer Order Count table.
- Identified the top 10 customers based on order count.
- Sorted customers from highest to lowest order count.
